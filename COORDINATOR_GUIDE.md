# Coordinator quick guide · SIDEQUEST classroom demo

**This is a simulated coordinator workspace. No actual Manila barangay, city department or agency receives these actions.**

1. From the public Home page choose Log in / Join, then **Try as coordinator**.
2. Open **Overview** to see the review queue, outstanding confirmations, rechecks, case categories and impact-priority flags.
3. Open a **New submission** from Overview or All reports. Check completeness, evidence, location, public-space relevance and any possible original report. If unclear, choose **Needs information** with a reason. If unsuitable, **Reject** and explain why. If duplicated, choose **Duplicate** and supply the original reference.
4. For a credible new case, move it to **Verified**. Only then can the reporter receive the one-time 20 XP award.
5. Open **Case coordination** to assign a demo coordinator, set impact priority, next review date, next public action and optional private note. Private notes should not appear in public case histories.
6. To demonstrate a referral, first change the case status to **Referred**. Then record **Referral sent** and, **only for a simulated acceptance acknowledgment**, check Referral accepted. A referral is never presumed accepted automatically.
7. Record visible progress updates in a public note. For a resolved case, attach an optional after photo; remember the original reporter photo remains private unless separately moderated.
8. **Confirmations:** review observation dates and optional evidence; approve credible unique confirmations for +10 XP or reject unsupported ones.
9. **Rechecks:** review challenged resolutions and decide whether to reopen the case. Record the reason.
10. **Reports and outputs:** Use filtered CSV and monthly aggregated summary, Analytics, and the case PDF / print-with-evidence buttons. All figures are fictional browser data.

**Prioritization:** Base urgency on risk/impact/accessibility, not on the number of confirmations or the reporter's XP. Keep audit entries factual and avoid sharing personal data in public notes.
