# SIDEQUEST V12 — Enhanced classroom demo

## What changed compared with V11

- Added a compact, personalized XP milestone on the public homepage, showing progress to the next level and the cosmetic rewards waiting ahead.
- Added three original neighborhood character designs: **Rooftop Watch**, **Corner Scout**, and **Street Guardian**, selectable from the homepage (signed-in users) and the explorer appearance editor. These are original illustrations, not Marvel characters or an official Marvel tie-in.
- Preserved the light mint/cream/lavender styling, original illustrated map and animated issue pins. A small rooftop skyline motif supports the street-level guardian concept without changing the color scheme.
- Preserved the optional neighborhood garden, where each plant corresponds to a recorded resolved case.
- Added an optional **View real Vito Cruz streets** panel to Explore. This uses an online OpenStreetMap embed to display actual street geometry. The map remains separate from SIDEQUEST's approximate report-pin illustration. If the embedded provider is blocked, the public OpenStreetMap link still works independently.
- Added a plain-language status explanation within Track, emphasizing that **referral sent** does not mean **referral accepted** or **resolved**.
- Expanded the Rewards view to explain the level-up event and the unlocks, including how to equip cosmetic profile frames.
- Improved small-screen layout for the new elements, while retaining V11's existing reporting, review, drafts, photo, admin, CSV, and PDF flows.

## What still works from V11

Public homepage; sign-in gate only for actions that require it; citizen demo registration and login; quick issue creation; local drafts; privacy notice and non-emergency scope; category descriptions; reference receipts; duplicate checks; I Experienced This Too; follow list and unread updates; coordinator cases/assignments/notes; referral sent vs accepted; resolution evidence; case history; CSV/monthly summaries; case PDF and print-with-evidence; responsive screens; EN/FIL navigation; XP and badges; neighborhood garden.

## Level rewards

| Level | Total verified XP | Gain |
|---|---:|---|
| 1 | 0 | New Explorer; standard frame |
| 2 | 100 | Neighborhood Helper; Leaf frame |
| 3 | 200 | Radar Scout; Sunrise frame |
| 4 | 300 | Taft Keeper title |
| 5 | 400 | Local Legend; Gold frame |
| 6 | 500 | Rooftop Guardian title; Rooftop frame |

Verified unique new concern: **+20 XP**; approved useful confirmation of an existing case: **+10 XP**. Demonstration cap: **60 XP per day**. XP is cosmetic recognition only; no monetary prizes, official school rewards, or priority in issue processing. Verification determines eligibility. Users cannot earn points for spam, duplicates, or rejected reports.

## Hosting and privacy limitations

This is a **static, browser-local classroom demo**. It does **not** create real shared accounts, secure admin permissions, authoritative case records, agency handoffs, or a secure cross-device database. A GitHub Pages deployment is a way to demonstrate the interface, **not** an operating citizen-reporting platform.

The optional real-streets embed requires an internet connection and may be blocked by some browsers/networks; the illustrated map stays usable. Report pin positions are approximate and are not suitable for navigation or emergency dispatch. All sample cases are fictional.

Do not enter real passwords, private evidence or identifying information. A public pilot requires formal agency partnership, security/privacy review, signed data agreements, backed-up infrastructure, moderation and production testing. See DEPLOYMENT_PLAN.md.
