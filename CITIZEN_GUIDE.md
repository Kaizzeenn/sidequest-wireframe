# Citizen quick guide · SIDEQUEST classroom demo

**For non-emergency concerns in the proposed Taft–Vito Cruz pilot area.** This prototype is not an official reporting service. Use invented sample information.

1. **Explore before signing in.** Open Home or Area Map. Search a landmark and inspect public sample issues. Use List view when the street map is difficult to navigate.
2. **Start a report.** Press Report a concern, sign in to the demo citizen account when ready, choose a category and area, and write a clear title and description. Place an approximate pin or use the optional GPS permission if supported.
3. **Look for a similar issue.** If a reviewed case already describes your experience, use **I experienced this too** instead of creating a duplicate. Choose the observation date and optionally attach helpful evidence.
4. **Save a draft.** If unfinished, choose Save draft. Return to the same browser/device and choose Restore draft. Photo files are not stored with drafts.
5. **Preview and submit.** Upload a photo if useful, remove or replace it, acknowledge the guidelines, then use **Review report**. Confirm details to receive a `SQ-DEMO-...` reference.
6. **Track and follow.** Search by reference ID, view the status history, coordinator, proposed office and next action. Follow a public case to see local-browser unread updates in My Activity. If asked for more information, respond via Track.
7. **Check the outcome.** A resolved case can still be challenged by an eligible reporter or confirmed contributor through Request a recheck.
8. **Earn optional XP.** The demo awards XP only after verification. Open My Activity > Rewards and badges to see level progress and equip cosmetic frames.

**Respect safety and privacy:** Never enter restricted/dangerous areas to earn points, and do not upload identifying faces, accusations or private information. For urgent threats, contact appropriate official responders directly.
